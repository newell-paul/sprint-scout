# Remove the segment target: spec

From the accepted intent of 1 November 2026.

## Behaviour

- **Segment screen.** The "Segment target time" section is gone. Shelter, then Elevation when the segment has heights, follow the cockpit as before.
- **Cockpit.** The target comparison block ("Target 1m 30s", the difference and its caveat) is gone.
- **Board.** Rows no longer carry the target difference. The shelter note stays.
- **Mobile.** No change beyond the missing section.

## Data and privacy

No change. Nothing new is stored or requested.

## Storage

- `DrawnRoute.targetTimeS` is removed.
- `readLibrary` drops `targetTimeS` whatever it holds, the same way it drops terrain and efforts. A library whose stored target was out of range used to fail to load; it now loads.
- Save no longer writes `targetTimeS`.

## Calculations

None. `attempt.ts` (`parseTarget`, `targetDifference`) is deleted.

## Tests

- **Unit:** `attempt.test.ts` deleted. The migration test expects the target dropped and the shelter kept. The property test generates any `targetTimeS` and checks it is dropped. A library test shows an out-of-range target no longer blocks loading.
- **Component:** `target-settings.browser.test.tsx` and its three baselines are deleted. The cockpit's target test and its baseline are deleted. The wind-preview target tests are removed. The wind-preview and board baselines that showed the target are regenerated by the test runner.
- **e2e:** `attempt.spec.ts` is deleted. The `Attempt` page object keeps only the conditions region used by the shelter spec. The rename test expects the target dropped and the shelter kept.

## Docs

- `docs/design.md`: "Segment target removed — 1 November 2026".
- `README.md`: the summary line drops "set a target time".
- `docs/test-strategy.md`: no change; its Targets section is about test metrics, not segment targets.
