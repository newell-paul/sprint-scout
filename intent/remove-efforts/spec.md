# Remove efforts and past wind: spec

From the accepted intent of 1 November 2026.

## Behaviour

- The selected segment no longer shows Your efforts, its import, its past-wind consent or Load past wind. Everything else in the wind preview is unchanged.
- Clear data's text reads "Delete every saved segment and rider setting from this browser" (it no longer mentions efforts).
- A redraw or save no longer carries efforts.

## Data and privacy

- No request to `archive-api.open-meteo.com`. It leaves the CSP `connect-src`.
- `readLibrary` drops `efforts` from every stored segment, whatever it holds, as it does for terrain fields. A library that only failed on malformed efforts now loads.
- Writes never include `efforts`.

## Calculations

- None change. `effort-match-v2` is removed with its module.

## Tests

- **Removed:** `effort-match.test.ts`, `archive-wind.test.ts`, `efforts-panel.browser.test.tsx`, `e2e/efforts.spec.ts`, the efforts page object and the `efforts-panel-two-laps` baseline.
- **Library:**
  - A stored segment with efforts, valid or malformed, loads without them.
  - The `v1-efforts` storage fixture stays as legacy input.
- **e2e:**
  - The privacy spec's archive test goes.
  - Open-Meteo call counts lose their `archive` field.
  - The drawing spec's rename test checks target and shelter only.
- **Stub:** the Playwright stub drops the archive route, so an archive request lands in `unhandled` and fails the test.
- **ARIA:** wind-preview component baselines are regenerated by the test runner.
